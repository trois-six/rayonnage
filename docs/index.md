# Foundation

* [Features](features.md) - The complete list of what Rayonnage does today, grouped by area, each feature in one line linked to the specification that defines it.
* [Quickstart](quickstart.md) - Requirements and procedures for installing a released package on Linux, Windows or macOS, or building Rayonnage from source, with the optional external programs and where the data lives.
* [Architecture](architecture.md) - Technology stack, module boundaries, storage, background jobs and archive access of the application.
* [Development](development.md) - Local development, tests, translations, development helpers, continuous integration and release automation.

# Features

* [Library](library.md) - The library folders and their scan, the formats read, what is read from each book, the book list with its columns, sorting, filters and in-place editing.
* [Book Information](book-info.md) - The Info dialog for one or several books, its tabs, the Pages tab that reorders, rotates and deletes pages, and automatic numbering.
* [Book Files](book-files.md) - Writing ComicInfo.xml into the book files, which formats can be written and how, and reading the information back from the files.
* [Conversion](conversion.md) - Conversion presets and the Export dialog to CBZ, CB7, CBR, CBT, PDF or an image folder, page naming, image processing, and the split of packs into albums.
* [Bedetheque](bedetheque.md) - Fetching book information from bedetheque.com: the lookup, the fields fetched, the options and the fallbacks.
* [File Organization](organizer.md) - Moving, copying or simulating the filing of book files from folder and file name templates, with profiles, exclusions, duplicates and undo.
* [ComicRack Import](comicrack-import.md) - Importing the settings of ComicRack CE and of its Bedetheque Scrapper 2 and Library Organizer plugins, and how Windows paths are mapped.
* [Interface](interface.md) - The main window, the message log, appearance, languages and keyboard shortcuts.
